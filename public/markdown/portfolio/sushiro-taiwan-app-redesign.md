# [App Redesign] 壽司郎App介面設計

針對壽司郎 App 導航層級較深、圖示風格不一致與核心功能不易尋找等問題，重新規劃底部導航、取號流程
與介面元件，讓取號、集點與優惠功能更容易抵達。


## 重點

- 重新規劃五項主要導航，讓取號、集點與優惠功能可以直接抵達
- 簡化取號流程，減少使用者在首頁與多層選單之間切換
- 建立一致的線性圖示、間距與元件樣式，改善原版介面視覺不一致
- 使用 Prototype 串接主要流程，檢查導航與操作回饋是否清楚

## 標籤

- UI/UX
- Figma
- Redesign

## 技能與工具

- https://thesvg.org/icons/figma/default.svg

## 詳細說明

- 本專案從實際操作壽司郎 App 出發，整理取號、集點、優惠與功能選單的操作路徑。原版介面存在主要功能入口較深、圖示風格不一致，以及資訊對齊與留白不足等問題。
- 重新設計以「快速找到到店前後常用功能」為目標，將取號、集點與優惠放入底部導航，減少使用者在首頁與功能選單之間切換。
- ＃本專案為個人 Figma 練習作品，非官方專案。

## 成果

- 完成取號、集點與優惠等核心功能的導航重整
- 建立符合原有品牌色的元件與圖示系統
- 透過 Prototype 檢查取號與主要頁面切換流程

## 設計理念

### 重新設計的底部導航列

規劃 5 個分頁架構，讓取號、集點、優惠一步到位。不需要一直切換選單列尋找功能，新設計的導航列能更直覺地找到App的主要功能。

![重新設計的底部導航列](https://res.cloudinary.com/dtzgfwzwf/image/upload/f_auto,q_auto,w_1200/v1774848610/3_detail_img_01_ermtfv.png)

### 以取號為例

目前版本：
首頁 → 選單 → 找到取號 → 填資料 → 完成（4步）
重設計後：
首頁 → 取號（底部導航直達）→ 填資料 → 完成（3步）

### 介面重新設計

以壽司郎既有紅白品牌色為基礎，重新整理字級、留白、按鈕與線性圖示。透過一致的圖示尺寸與線條粗細，改善原版介面中圖示風格與視覺重量不一致的問題。

![介面重新設計](https://res.cloudinary.com/dtzgfwzwf/image/upload/f_auto,q_auto,w_1200/v1774848612/3_detail_img_02_yku9dd.png)

### 取號介面

重新排版對齊與留白，讓關鍵資訊更容易閱讀。

![取號介面](https://res.cloudinary.com/dtzgfwzwf/image/upload/f_auto,q_auto,w_1200/v1774848615/3_detail_img_03_quza1y.png)

### 統一風格的icon

以線條重新設計各個功能的icon，解決目前版本icon風格、尺寸凌亂的問題。

![統一風格的icon](https://res.cloudinary.com/dtzgfwzwf/image/upload/f_auto,q_auto,w_1200/v1774849659/3_detail_img_04_axj4vd.png)
