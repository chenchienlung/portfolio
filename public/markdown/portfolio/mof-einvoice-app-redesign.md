# [App Redesign] 財政部統一發票兌獎App介面設計

針對財政部統一發票兌獎App介面缺點與使用上的痛點，修改成更現代化的介面排版，提升使用者體驗，減少操作步驟。


## 重點

- 重新設計底部導航列架構，減少首頁、發票存摺與功能選單之間的反覆切換
- 重新整理發票明細的資訊層級，使用「卡片」區分不同類型的交易資料
- 重新設計各功能icon，提升辨識度與一致性
- 使用 Prototype 走查主要任務流程，確認導航與頁面切換邏輯

## 標籤

- UI/UX
- Figma
- Redesign

## 技能與工具

- Figma

## 詳細說明

- 本專案從實際操作財政部統一發票兌獎 App 出發，原版 App 因缺少底部導航列，常用功能入口較深、首頁與功能選單需要反覆切換，以及發票明細資訊較為分散等問題。
- 重新設計的目標是讓發票存摺、對獎與常用功能更容易抵達，同時重新整理發票明細的資訊層級，使不同年齡層的使用者都能更快速找到交易資訊。
- ＃本專案為個人 Figma 練習作品，非官方專案。

## 成果

- 完成原版 App 的操作流程盤點與主要痛點整理
- 重新規劃底部導航，降低常用功能的尋找成本
- 重新設計發票明細的資訊層級與元件結構
- 重新設計功能圖示
- 使用 Prototype 模擬主要任務流程，確認導航與頁面切換邏輯

## 設計理念

### 新增底部導航欄

將App中最常用的3個功能，以及首頁和功能表共 5 個按鈕加入導航列中，降低跨層選單切換。重新規劃後，使用者可以從目前頁面直接切換主要功能，不必每次返回首頁重新尋找入口。

![新增底部導航欄](https://res.cloudinary.com/dtzgfwzwf/image/upload/f_auto,q_auto,w_1200/v1774847641/2_detail_img_01_umg9h7.png)

### 例如：首頁 → 發票存摺 → 對獎，然後再返回首頁

原版路徑：
首頁 → 發票存摺 → 選單 → 對獎 → 選單→ 首頁
Redesign：
首頁 → 發票存摺 → 對獎 → 首頁

### 發票明細資訊分層

原版發票明細中的資訊較為分散，因此將相關資料重新分組並使用卡片呈現。透過標題、留白與字級差異建立閱讀順序，讓使用者更容易找到並輕鬆讀取該筆交易資訊。

![發票明細資訊分層](https://res.cloudinary.com/dtzgfwzwf/image/upload/f_auto,q_auto,w_1200/v1775802727/2_detail_img_02_qac60a.png)
